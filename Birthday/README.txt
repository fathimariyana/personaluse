RAHIL BIRTHDAY WEBSITE — PERSONALIZED SURPRISE EDITION

HOW TO OPEN
1. Extract this ZIP into a new folder.
2. Open the extracted folder in VS Code.
3. Right-click index.html and choose Open with Live Server.

FEATURES
- Two-step welcome: he types the special name you call him, then sees “Hoo, that's too lovely…” with that name before entering the website.
- Visible pink birthday candle with wick and glowing flame, a 5-second countdown, and a blow-out button.
- When the candle is blown out, a butterfly burst, floating hearts, and the birthday wish appear.
- Full scrapbook spread showing four photos at once. Add up to 12 photos.
- Ten glowing constellation stars; each reveals a different love note in a styled message card.
- Full-screen animated virtual hug with floating hearts, butterflies, and sparkles. Close it with the X or Escape key.
- Virtual gift, birthday letter, optional music, date ideas, future list, and final heart celebration.

ADDING PHOTOS
Put your images in the photos folder and name them:
memory1.jpg, memory2.jpg, memory3.jpg ... memory12.jpg
Use JPG images for the easiest setup. Missing images show cute placeholders.

OPTIONAL MUSIC
Place your audio file beside index.html and name it music.mp3.

NOTES
- Use this latest extracted folder, not an older copy.
- Browser audio only plays after the visitor presses the music button.
- To share by QR code, publish the website online first (for example with GitHub Pages), then create a QR code from the public URL.
